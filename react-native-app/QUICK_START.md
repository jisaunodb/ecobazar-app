# 🚀 VS Code-এ এই React Native অ্যাপটি চালানোর ৩টি সহজ ধাপ

আপনার ব্যাকএন্ড লিংক (`https://ecobazar-backend-1qs6.onrender.com`) ইতিমধ্যে কোডে যুক্ত করে দেওয়া হয়েছে!

---

### ধাপ ১: VS Code-এ শুধু `react-native-app` ফোল্ডারটি ওপেন করুন
1. **VS Code** ওপেন করুন।
2. মেনু থেকে যান: **File ➔ Open Folder...**
3. শুধু **`react-native-app`** ফোল্ডারটি সিলেক্ট করে **Open** করুন।
   *(গুরুত্বপূর্ণ: পুরো প্রজেক্ট রুট ফোল্ডার ওপেন করবেন না, কেবল `react-native-app` ফোল্ডারটি ওপেন করবেন)*

---

### ধাপ ২: টার্মিনালে নিচের ২টি কমান্ড দিন
VS Code-এর ভেতরে নিচের টার্মিনাল ওপেন করুন (`Ctrl + \`` বা `Terminal ➔ New Terminal`), তারপর রান করুন:

```bash
npm install
```
ডিপেন্ডেন্সি ইনস্টল শেষ হলে রান করুন:
```bash
npx expo start
```

---

### ধাপ ৩: ফোনে ওপেন করুন
টার্মিনালে একটি বড় **QR Code** আসবে।
1. আপনার ফোনে **Expo Go** অ্যাপ ওপেন করুন (Play Store / App Store থেকে নামানো)।
2. **Scan QR code** দিয়ে টার্মিনালের কোডটি স্ক্যান করুন।

✨ সাথে সাথে আপনার ফোনে **EcoBazar** মোবাইল অ্যাপ চালু হয়ে যাবে!

---

### 🌐 আপনার ব্যাকএন্ড লিংক কনফিগারেশন:
আপনার রেন্ডার ব্যাকএন্ড লিংকটি ইতিমধ্যে `App.js` এবং `StandaloneApp.js`-এ সেট করা আছে:
```javascript
const BACKEND_API_URL = "https://ecobazar-backend-1qs6.onrender.com";
```
আপনার ব্যাকএন্ডে যখন `/products` বা `/orders` এন্ডপয়েন্ট সক্রিয় থাকবে, অ্যাপটি সরাসরি আপনার রেন্ডার সার্ভার থেকে প্রোডাক্ট আনবে এবং নতুন অর্ডার পুশ করবে।
